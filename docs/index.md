# Fluxbit ViewComponents

UI Component Library for Ruby on Rails built on **Flowbite** and **Tailwind CSS**.

[Get Started]({{ '/01_Getting_Started/' | relative_url }}){: .btn .btn-primary .fs-5 .mb-4 .mb-md-0 .mr-2 }
[GitHub](https://github.com/arthurmolina/fluxbit_view_components){: .btn .fs-5 .mb-4 .mb-md-0 target="_blank" }

---

Fluxbit ViewComponents is a collection of UI components for Ruby on Rails applications, inspired by the [Flowbite](https://flowbite.com) component library and built using Tailwind CSS. These components help developers create modern, responsive, and accessible web applications with ease.

## Quick Install

```sh
bundle add fluxbit_view_components
bin/rails fluxbit_view_components:install
```

## What's Included

| Category | Components |
|:---------|:-----------|
| **UI Components** | Alert, Badge, Button, Card, Modal, Drawer, Dropdown, Accordion, Carousel, and more |
| **Navigation** | Breadcrumb, Pagination, Tab, Bottom Navigation, Speed Dial |
| **Forms** | Text Field, Checkbox, Toggle, Range, Select, Dropzone, Upload Image |
| **Typography** | Heading, Text |
| **Generators** | Scaffold generator with Turbo, Pundit, Pagy/Kaminari support |
| **JavaScript** | Stimulus controllers for common UI patterns |
